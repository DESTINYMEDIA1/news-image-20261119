# The World in One Day — Thursday 19 November 2026

A 1024×1024 newspaper front page summing up the world's news of Thursday 19 November 2026, in 24 stories: Trump, Xi and Putin's first three-way talks in Shenzhen; the ICJ ruling that Myanmar committed genocide against the Rohingya; and GTA VI launching worldwide.

## Entry

- `entry.png` — the front page (1024×1024 PNG, under 1 MiB)
- `main.py` — Python 3.13, standard library only; copies `entry.png` to `/output/entry.png`, deterministically, with no network

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`
